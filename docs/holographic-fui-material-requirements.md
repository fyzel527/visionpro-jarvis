# visionOS 全息 FUI 材质开发需求

## 目标

在 visionOS 2.0+、RealityKit、SwiftUI `RealityView` 和 `ImmersiveSpace` 中实现影视级 JARVIS 全息光介质。目标是“由光构成的空间物体”，不是发光屏幕、纯色边框或黑色半透明底板。

## 核心约束

- RealityKit + MaterialX 自定义材质；禁止 Sprite2D 和普通 PBR 材质。
- Additive 加法混合；亮部叠加增亮。
- 完全 Unlit 自发光，不受现实环境光照影响。
- 面向 Vision Pro 优化，支持多个面板实例。
- 所有视觉效果都能由 Swift 运行时调参。
- 支持薄平面、曲面、模型表面和 SwiftUI Attachment 叠加。

## MaterialX 视觉效果

1. 菲涅尔边缘发光：可调强度和幂次；正视中心压低、切线边缘增强。
2. 时间驱动程序化噪声：模拟介质尘埃和信号杂讯；参数包括强度、缩放、速度。
3. 噪声驱动边缘消融：随机透明消散、光屑外弥散；可调阈值和扰动强度。
4. 边缘局部 RGB 色散：可调偏移幅度，可关闭，不做全局偏移。
5. 全局微弱抖动闪烁：可调幅度、频率和开关，避免刺眼。
6. 默认冷青蓝主色，支持琥珀橙高光色；亮度全部来自自发光。
7. 正视半透明、侧视高亮，同时保持透光和多层叠加。

## Swift + RealityKit 交付

- 可复用 `HolographicComponent`：自动应用材质，暴露主色、菲涅尔、噪声速度、色散、消融和运行时更新接口。
- 分层方案：薄平面作为光介质外壳，SwiftUI Attachment 只负责文字、图表、线条；支持不同 Z 深度。
- 可选 `ParticleEmitterComponent` 边缘散射粒子，参数包括数量、生命周期、发射速率。
- 动画预设：浮现、边缘扫描波、中心向外扫描脉冲、休眠和激活状态。
- 最小示例：ImmersiveSpace 中放置 2-3 个多层全息面板。
- 提供完整 `.mtlx`、Swift 封装、示例代码、粒子配置、参数说明和性能提示。

## 禁止实现

- 黑色半透明底板。
- 普通 PBR 或依赖环境光照。
- 只有 CSS 式纯色描边。
- 静态扫描线贴图代替程序化噪声。
- 将文字全部写进 MaterialX；文字必须由 SwiftUI Attachment 提供。

## 可选扩展

- 将材质投射到 3D 模型表面，用于物体扫描分析。
- 手部靠近实体时提高全息亮度。
